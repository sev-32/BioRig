# Clothing Engine R1 handoff operating rules

This directory is a **provenance and import registry** for an external transfer archive. It is NOT the unpacked simulation source tree.

1. Do not claim ZIP contents are in Git: the full asset archive is separately distributed. Verify SHA-256 before use.
2. Read the imported archive's root `AGENTS.md`, `CURRENT_STATE.md`, `SOURCE_PERSISTENCE_NOTE.md` and `docs/FINAL_PROMOTION_MATRIX.md`.
3. Keep a strict distinction between byte-identical recovered code, experiment JSON evidence, and proposed late manifold mechanisms that have no persisted source.
4. Do not promote solver changes from a one-frame run. Use high-amplitude motion, deep knee axial/circumferential oracle, finite-state, garment-body penetration, strain, and relative-speed tests.
5. Correct the dense tube oracle's candidate-selection bias (all live denim triangles vs rest-axial prefilter) before trusting any geometric closure result.
6. Show actual engine-native renderer captures for visual checkpoints; only the user approves visuals. Existing contact sheets are baselines, not approval of new code.
7. Keep changes on explicit branches with hashes, measurement JSON, exact tested configuration and reproduction instructions. Do not rewrite pre-existing BioRig research branches.
8. Do not accumulate replicated F32/U32 qualification snapshots or redundant render dumps in handoff archives. Retain summaries and sufficient evidence, with a transparent removal ledger.
