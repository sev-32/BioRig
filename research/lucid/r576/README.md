# R576 — post-lock long-horizon support (research only)

This module is an **executable** 12-second paired experiment against the untouched R574 MuJoCo free-root 84-muscle rig. It does **not** change R574, R575, their hashes, their learned goal selector, or the lower-level motor plant. R574 chooses `none` or `R28` at 60 ms using only sensed state. An optional R562-derived late-support guard observes the **current** physical contact and body state every 40 ms and commands bounded muscle excitation if support is drifting. It neither observes harness force metadata nor looks at counterfactual future outcomes during execution. All conditions clone the same saved initial plant state.

## Restore runtime

From repository root, supply the **original** immutable R574 and R575 archive ZIPs; they are not stored in Git history:

```bash
python research/lucid/tools/bootstrap.py \
  --r574 /path/LUCID_R574_GOAL_CONDITIONED_MUSCLE_INTENT_SELF_CONTAINED.zip \
  --r575 /path/LUCID_R575_VERIFIED_TAKEOVER_LATENCY_ADDENDUM.zip \
  --destination ./runtime

python research/lucid/r576/r576_longhorizon.py \
  --indices 0 --seconds 12 --trace --out ./R576_SCENE00_PAIRED_12S.json

python -m unittest discover -s research/lucid/r576 -p 'test_r576.py' -v
R576_RUN_NATIVE=1 python -m unittest discover -s research/lucid/r576 -p 'test_r576.py' -v
```

Requires Python 3.13, MuJoCo 3.15, NumPy and scikit-learn. The physics-enabled test replays the entire native 12-second paired experiment (~20–30 seconds on the development machine). Rendering additionally requires PyOpenGL and EGL: `MUJOCO_GL=egl python research/lucid/r576/r576_render.py`. `runtime` is discovered in this module's directory or a parent folder.

## Native scene 00: independently cloned 12-second development pairing

| Metric | Frozen R574 | R576 guarded |
| --- | ---: | ---: |
| Applied perturbation | 0 N | 0 N |
| Selected early muscle action | none | none |
| Peak root tilt | 103.883949° | 26.348198° |
| Peak arm-seat contact | 1618.530502 N | 4.289241 N |
| Peak other-floor contact | 1519.315246 N | 0 N |
| Both-support-loss samples | 7 | 0 |
| Project hazard at 12 s | yes | no |
| Settled at 12 s | no | **no** |
| Late support muscle pulses | 0 | 4 |

Four R562-derived left-lateral pulses started at 4.44, 9.52, 10.56 and 11.64 s. These pulses **prevented the measured fall at 12 seconds**; the final guarded root tilt is still 26.35° and therefore **this is not stabilized equilibrium**. The original rig had not received a push and passed its 8-second criterion before failing near 11.32 seconds. This case was selected **after** the observed failure, so these are exploratory *development* results, not independent held-out policy validation.

`R576_SCENE00_COMPACT_RECEIPT.json` records source-lock and initial-state fingerprints, numerical outcomes and SHA-256 of the complete trace and native renderer PNG. The ~170 KB full trace and a renderer-captured ~649 KB PNG were produced locally; they are not included in this small source-only Git tree. The user-facing rendered comparison is provided separately, not generated by an image model.

Scene 04's 12-second paired runner emitted that both branches remained safe and settled with **zero guard pulses**, but the multi-scene job later timed out on scene 07 before writing its aggregate output. Treat scene 04 as a console-observed result, not as a persisted receipt. Scene 07 and other scene coverage remain **unverified in R576**.

## Stop/go gate

Do **not** promote R576 to the canonical R574 controller yet. Next: capture the no-push plant's continuous controller/muscle/contact state to isolate the >10 s drift mechanism; prove passive long-horizon stability to at least 30/60 s; complete 14-scene matched 12-second cases with runtime limits and per-case checkpointing; check R576 action-induced hazards, all 8-second frozen regression anchors, sensitivity to contact/muscle settings, and eventually delay *all* sensorimotor feedback paths (not just R575 high-level sensing). Never interpret simulated peak loads as calibrated human injury thresholds.
